## How I practise

1. Learn a concept and write a short explanation in my own words.
2. Practise it in a terminal, simulator, or lab environment.
3. Record the commands or steps I used and the outcome.
4. Document errors, troubleshooting steps, and what I learned.
5. Revisit the topic and build on it with a small practical exercise.

## Projects and practical work

I'm building towards practical defensive-security projects. Planned areas include:

- **Network analysis:** Capture and inspect traffic with Wireshark; explain protocols and suspicious patterns.
- **Python for security:** Write beginner-friendly scripts for parsing text, analysing sample logs, and automating simple tasks.
- **Linux security practice:** Work with users, groups, file permissions, processes, and system logs.
- **SOC investigation practice:** Analyse safe sample logs, identify notable events, and document an investigation from alert to conclusion.

Projects will be added here as I complete them. I will distinguish completed work from planned work.
